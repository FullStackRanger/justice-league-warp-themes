## Image Requirements

- **Format**: JPEG (.jpg or .jpeg)
- **Recommended Resolution**: 1920x1080 or higher (4K preferred)
- **Aspect Ratio**: 16:9 (landscape)
- **File Size**: Keep under 5MB for optimal performance

## Quick Download Guide

1. Visit the wallpaper sites linked above
2. Search for the character name
3. Select a high-quality image (1920x1080 minimum)
4. Download the image
5. Convert to JPG if needed (most sites provide JPG)
6. Rename the file to match the naming convention
7. Place in: `~/.local/share/warp-terminal/themes/justice-league/`

## Alternative: Using wget or curl

If you find a direct image URL, you can download using command line:

```bash
# Example (replace URL with actual image URL):
cd ~/.local/share/warp-terminal/themes/justice-league/

# Green Lantern example
wget -O green-lantern.jpg "https://example.com/green-lantern-wallpaper.jpg"

# Or using curl
curl -o batman.jpg "https://example.com/batman-wallpaper.jpg"
```

## Image Conversion (if needed)

If you download a PNG file, convert it to JPG:

```bash
# Using ImageMagick
convert image.png image.jpg

# Or using ffmpeg
ffmpeg -i image.png image.jpg
```

## Testing Your Theme

After downloading and placing images:

1. Open Warp Terminal
2. Go to Settings → Appearance → Themes
3. Search for your Justice League character theme
4. Select it to preview
5. The background should appear at 20% opacity

## Troubleshooting

**Theme doesn't show background:**
- Verify file name matches exactly (case-sensitive)
- Ensure file is in JPG format
- Check file is in the correct directory
- Try restarting Warp

**Background too faint or too strong:**
- Edit the theme's YAML file
- Adjust `opacity` value (0-100)
- Save and theme will auto-reload

**Image looks pixelated:**
- Download a higher resolution version
- Recommended: 2560x1440 or 3840x2160 (4K)

## Recommended Image Style

For best results, look for:
- **Green Lantern**: Glowing ring energy, green color dominant
- **Wonder Woman**: Heroic pose, red/gold colors, lasso of truth
- **Superman**: Flying or iconic S-shield, blue/red dominant
- **Batman**: Dark Gotham aesthetic, silhouettes, cityscape
- **Aquaman**: Underwater scenes, ocean blue/green tones
- **Flash**: Lightning effects, speed force, red/yellow dominant
- **Martian Manhunter**: Space or Mars themes, green skin prominent
- **Shazam**: Lightning bolt, magical energy, red/gold dominant
