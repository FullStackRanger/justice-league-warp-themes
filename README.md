# Justice League Warp Themes

A collection of 8 Warp terminal themes based on DC Comics' Justice League characters, featuring character-specific color schemes and support for background images at 20% opacity.

## Themes Included

1. **Green Lantern** - Bright green energy theme with emerald accents
2. **Wonder Woman** - Red, gold, and blue royal theme  
3. **Superman** - Classic red and blue with yellow accents
4. **Batman** - Dark Gotham theme with gold highlights
5. **Aquaman** - Ocean depths theme with orange and teal
6. **Flash** - Speed force theme with red and yellow lightning
7. **Martian Manhunter** - Martian green with red accents
8. **Shazam** - Lightning bolt theme with red and gold

## Installation

### 1. Install Theme Files

The YAML theme files are already installed at:
```bash
~/.local/share/warp-terminal/themes/justice-league/
```

### 2. Download Background Images

For each theme you want to use, download a high-quality background image:

**Recommended sources:**
- [Wallpapers.com](https://wallpapers.com)
- [WallpaperFlare](https://www.wallpaperflare.com)
- [Alpha Coders](https://wall.alphacoders.com)

**Search terms:**
- "Green Lantern DC Comics wallpaper"
- "Wonder Woman DC wallpaper"  
- "Superman DC wallpaper"
- "Batman DC wallpaper"
- "Aquaman DC wallpaper"
- "Flash DC Comics wallpaper"
- "Martian Manhunter DC wallpaper"
- "Shazam DC wallpaper"

### 3. Place Images

Save downloaded images (in JPG format) to:
```bash
~/.local/share/warp-terminal/themes/justice-league/
```

**Image naming:**
- `green-lantern.jpg`
- `wonder-woman.jpg`
- `superman.jpg`
- `batman.jpg`
- `aquaman.jpg`
- `flash.jpg`
- `martian-manhunter.jpg`
- `shazam.jpg`

### 4. Activate Theme

1. Open Warp Terminal
2. Press `Ctrl+Shift+P` or navigate to Settings → Appearance → Themes
3. Search for and select your desired Justice League theme
4. The theme will activate immediately

## Theme Features

- **Background Opacity**: All themes set background images to 20% opacity for optimal readability
- **Character Color Schemes**: Each theme uses colors inspired by the character's costume and powers
- **Dark Mode**: All themes are optimized for dark mode (`details: darker`)
- **Full ANSI Support**: Complete terminal color support with normal and bright variants

## Customization

To customize a theme:

1. Edit the YAML file: `~/.local/share/warp-terminal/themes/justice-league/<character>.yaml`
2. Modify colors (use hex format: `#RRGGBB`)
3. Adjust `opacity` value (0-100, where 20 is subtle, 100 is fully opaque)
4. Save the file - Warp will automatically reload the theme

## Contributing to Official Repo

These themes can be submitted to the official Warp themes repository at:
